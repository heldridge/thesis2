We present here a construction for MDSS that achieves MD-correctness for $\mdssMaxDealers < \frac{\mdssRecThr}{\mdssPrivThr}$ dealers.
Our scheme is based on a variant of Shamir's secret sharing scheme \cite{Shamir79}.
Recall that in Shamir's secret sharing, a secret $\mdssSecret$ is an element of a finite field $\FF$: to share $\mdssSecret$, one samples a random polynomial $p \in \FF[x]$ with degree $\mdssPrivThr$ under the constraint that $p(0) = s$.
The $i$-th share is simply the pair $(i, p(i))$ where $i \in \FF \setminus 0$ is a fixed evaluation point.

This scheme is {\em not} unlinkable: consider a set of shares where two of the shares $(i,y)$ and $(i',y')$ are such that $i=i'$ while  $y\neq y'$.
Given such a set, an adversary can determine with probability $1$ that these shares correspond to {\em different} secrets.
To achieve unlinkability, we therefore we allow the share algorithm to sample each evaluation point uniformly at random from $\FF \setminus 0$.
If $\FF$ has size super-polynomial in the security parameter $\secpar$, any two evaluation points collide with probability negligible in $\secpar$.
Crucially, this probability is the same for any two shares, {\em irrespective of whether they correspond to the same or different secrets}.

To achieve MD-correctness, we start with the observation that a collection of Shamir secret shares can be viewed as a Reed-Solomon codeword \cite{localReeSol60, localMcEliece81}.
Therefore, recovering a secret from a collection of Shamir secret shares in the presence of noise is equivalent to the problem of Reed-Solomon decoding, and a natural choice for $\mdssReconstructAlg$ is an algorithm based on a Reed-Solomon decoder.
Suppose that a single dealer supplies $\mdssNumShares$ shares in a set of size $\mdssWindowSize \leq \mdssMaxShares$, and we would like to know if recovering the secret input of this dealer is possible.
From a coding theory perspective, we may consider the set of shares to be a word that is distance $\mdssWindowSize-\mdssNumShares$ away from an equivalent length Reed-Solomon codeword corresponding to the dealer's input.
As long as an RS decoder exists which can recover from a fraction of $1 - \frac{\mdssNumShares}{\mdssWindowSize}$ errors, we can recover the dealer's secret.

This, however, is not an easy condition to satisfy for a large numbers of dealers; as one example, for any non-trivial scheme with $\mdssMaxDealers > 1$, we cannot use a unique decoding algorithm.
Nevertheless, our problem setting can be mapped onto that of list-decoding, which can tolerate higher error (in the ramp setting) and support recovery of multiple polynomials (with enough evaluations).
A well-known list-decoding algorithm for Reed-Solomon codes is the one devised by Guruswami and Sudan (GS) ~\cite{FOCS:GurSud98}, and indeed we can use their algorithm as the principal component of $\mdssReconstructAlg$ to produce a scheme that we describe below.
First, however, we must state what is guaranteed by the GS decoder.

\begin{theorem}[Due to \cite{FOCS:GurSud98}]
	Let $\FF$ be a finite field.
	Let $\mdssPrivThr$, $\mdssRecThr$, $\mdssWindowSize$ be positive integers such that $\mdssRecThr > \sqrt{\mdssPrivThr\mdssWindowSize}$.
	Then there exists an algorithm $\gsDecode(\mdssPrivThr, \mdssRecThr, \set{(x_i, y_i)}_{i\in[\mdssWindowSize]})$ where for all $i$: $x_i, y_i \in \FF$, that outputs all univariate polynomials $p$ of degree at most $\mdssPrivThr$ such that $y_i = p(x_i)$ for at least $\mdssRecThr$ values of $i \in [\mdssWindowSize]$.
\end{theorem}

We can now formally describe our GS-based construction.
\begin{pcvstack}[boxed, center, space=1em]
	\procedure[linenumbering]{$\mdssShareAlg(\secparam, \mdssSecret, \mdssNumShares)$}{
		\text{Sample a polynomial } p \text{ of degree } \mdssPrivThr \text{ where } \mdssSecret = p(0) \\
		\text{Sample } \mdssNumShares \text{ field elements } x_1, \dots, x_\mdssNumShares \sample \FF \\
		\pcreturn \set{(x_i, p(x_i))}_{i \in [\mdssNumShares]}
	}

	\procedure[linenumbering]{$\mdssReconstructAlg(\mdssBlindShare_1, \dots, \mdssBlindShare_{\mdssWindowSize})$}{
		p_1,\dots,p_{\mdssNumShareSets} \gets \gsDecode(\mdssPrivThr, \mdssRecThr, \set{\mdssBlindShare_1, \dots, \mdssBlindShare_{\mdssWindowSize}}) \\
		\pcreturn \set{p_1(0), \dots, p_{\mdssNumShareSets}(0)}
	}
\end{pcvstack}
