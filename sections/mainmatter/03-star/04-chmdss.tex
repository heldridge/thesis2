We will require less stringent security and correctness requirements than those described in \cref{chap:mdss}.
Specifically, for unlinkability and md-correctness, we will require that the respective properties only hold when all indices are \emph{unique}.
We describe these properties formally below.

\begin{definition}[Weak Unlinkability]
	Weak unlinkability for an MDSS scheme $\mdss$ is defined identically to \cref{def:unlinkability}, with the addition of the following admissibility condition on the adversary $\adv$:
	\begin{itemize}
		\item For $b \in \bin$, all elements of $\indexSet_{1, b}, \dots, \indexSet_{\mdssNumShareSets, b}$ are unique
	\end{itemize}
\end{definition}

\begin{definition}[Weak MD-Correctness]
	Weak md-correctness for an MDSS scheme $\mdss$ is defined identically to \cref{def:md-correctness}, with the addition of the following requirement for when it must hold:
	\begin{itemize}
		\item $\bigcup_{i, j \in [\mdssNumShareSets] \text{s.t.\ } i \neq j} \indexSet_i \cap \indexSet_j = \emptyset$
	\end{itemize}

	Stated intuitively, correctness is only required to hold when all indices are unique.
\end{definition}

We can now state the relevant theorems regarding \chmdss{}.
We note that, as described in \cite{\citeairtag}, the \chmdss{} algorithm is only \emph{heuristically} correct, with no formal proof of correctness.
We provide the heuristic assumption that we rely on, which is substantially similar to the heuristic assumption originally described in \cite{\citeairtag}, in \cref{sec:chmdss-proofs}.

\begin{theorem}
	For all $\np > 1$ and finite fields $\FF$, the construction shown in \cref{fig:chmdss} satisfies weak $\mdssULVar$-unlinkability for $\mdssULVar(\secpar) = 0$.
\end{theorem}

\begin{theorem}
	For all sets of parameters satisfying $\mdssRecThr \geq \frac{1}{\np + 1}(\mdssMaxShares + (\np \cdot (\mdssPrivThr + 1)))$ and finite fields $\FF$, the construction shown in \cref{fig:chmdss} heuristically satisfies weak $\mdssCVar$-correctness for a negligibly small $\mdssCVar(\secpar)$.
\end{theorem}

As the proofs that $\chmdss$ satisfies these properties are substantially similar to the proofs provided in \cite{\citeairtag}, we delegate them to \cref{sec:chmdss-proofs}.
